Sistema integral de gestión para Nictech
Quiero desarrollar un sistema de gestión propio para Nictech, tomando como referencia las funciones de reparación de Samii y la gestión comercial, administrativa y financiera de Don Gestión, pero adaptado completamente al funcionamiento del negocio.
El sistema debe centralizar productos, compras, stock, ventas, caja, pedidos online, reparaciones, presupuestos, clientes, armados de PC, equipos recibidos como parte de pago, facturación, WhatsApp, financiación, contabilidad e informes.
1. Separación entre la página y el sistema
La página web pública y el sistema de gestión deben ser aplicaciones diferenciadas.
La página continuará destinada a los clientes y tendrá:
Catálogo y tienda.
Compra de productos.
Seguimiento de reparaciones.
Información pública de Nictech.
El sistema será privado y podrá utilizar una dirección como:
gestion.nictech.com.ar
sistema.nictech.com.ar
También puede existir en la página un botón “Iniciar sesión” que dirija al sistema, pero la gestión no debe formar parte del área pública.
Ambas aplicaciones estarán conectadas mediante una API y utilizarán una fuente central de productos, precios, disponibilidad y operaciones. El acceso interno requerirá usuario, contraseña, permisos y sesiones seguras.

14. Sincronización de stock con la página
Si un producto se vende en el local:
Se confirma la venta.
Se descuenta del inventario.
Se actualiza el stock web.
Si llega a cero, se oculta, pausa o muestra agotado.
Si alguien compra online:
Se genera el pedido.
Se reserva el stock.
La disponibilidad web disminuye.
Si se acredita el pago, la reserva se convierte en venta.
Si el pedido vence o se cancela, el stock se libera.
La sincronización debe registrar errores y reintentar. El sistema debe mostrar si un producto no pudo actualizarse en la página.
